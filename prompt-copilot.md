# Prompt pro GitHub Copilot

Vytvoř responzivní, přístupnou a obsahově správnou českou vzdělávací webovou stránku na téma algoritmizace. Stránka má začátečníkům vysvětlit, co je algoritmus, jaké vlastnosti má mít a jak se znázorňuje vývojovým diagramem. Přidej krátký interaktivní test.

## Obsah

- Vysvětli vlastními slovy pojem algoritmus a vztah mezi návrhem algoritmu a programováním.
- Představ těchto šest vlastností: konečnost, věcná správnost, jednoznačnost, obecnost, opakovatelnost a srozumitelnost.
- Upozorni na podmínky řešitelnosti, například dělení nulou a odmocninu ze záporného čísla v oboru reálných čísel.
- Popiš základní značky vývojového diagramu: ovál pro začátek/konec, kosodélník pro vstup/výstup, obdélník pro zpracování a kosočtverec pro rozhodnutí. U rozhodnutí ukaž popsané větve, například ANO a NE.
- Přidej kvíz s výběrem odpovědi, kontrolou výsledku, srozumitelnou zpětnou vazbou a možností začít znovu.

## Zpracování zdrojů

Vycházej z dodaných studijních souborů `algo1.md`, `ALGORITMIZACE.pdf` a `vyvojove_diagramy.pdf`. Vysvětlení formuluj nově a stručně; nepřebírej celé pasáže, testové otázky ani obrázky ze zdrojů. Zdroje uveď v souboru `citace.md`. Pokud u podkladu nejsou známé bibliografické údaje, transparentně to poznamenej a nic nedoplňuj odhadem.

## Technické a přístupnostní požadavky

- Použij sémantické HTML, samostatné CSS a prostý JavaScript bez frameworků a externích knihoven.
- Piš česky, nastav správný jazyk dokumentu, přidej popis stránky, responzivní rozvržení, viditelné focus stavy, popisky formulářových prvků a stavové hlášení pro výsledek kvízu.
- Zajisti čitelnost na mobilu, dostatečný kontrast a respektuj nastavení omezení animací.
- Nepoužívej nefunkční odkazy ani neověřené údaje. Všechny interakce otestuj.
- Zachovej přehledný, přívětivý vizuální styl s jednoduchou vlastní grafikou. Nepoužívej obsah stažený z cizích stránek.

## Výstup

Vytvoř funkční statický web, který lze publikovat jako GitHub Pages z kořene repozitáře. Udržuj obsah přesný, stručný a vhodný pro školní výuku.
